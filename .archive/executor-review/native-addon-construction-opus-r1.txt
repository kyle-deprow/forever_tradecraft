## Must

1. **Recovery can't be reached in production.**
   - **Where:** `Commands.lua:183` only runs `BeginRecovery` if `Agent.RecoveryAdmitted()` is already true. The only things that set it are `Agent.AdmitRecovery()` (`Agent.lua:524-527`), which nothing in production calls, and Restore's 2-second timer, which itself needs admission (`Agent.lua:569`). The test reaches Restore by calling the bypass directly (`test_addon.py:395`).
   - **Second defect:** even if admission worked, `recover` never refreshes the panel. In armed/deferred loads Construct stays visible, so the helper's negative Construct template check fails.
   - **Consequence:** once any marker exists (armed, deferred, constructing, failed, constructed, malformed, or post-Finalize), every later load keeps the scanner blocked. The only way out is a manual SavedVariables edit, which is forbidden.
   - **Correction:**
     - Make the fixed `/crowley agent recover` command the admission, owned by Commands.
     - Accept it only when a marker exists, the decision isn't ordinary, or the lifecycle is `finalized`.
     - Refuse it in a plain ordinary load with no marker, and in a restore_pending state.
     - On acceptance: enter recovery mode, revoke any release, generate the nonce, and call `updatePanel()`.
     - Delete `Agent.AdmitRecovery`, and test every state through `slash("agent recover")` plus a Restore click.

2. **The deferred Construct path has no 1 Hz publisher, and Finalize publishes nothing.**
   - **Where:** `constructDeferred` (`Agent.lua:547-561`) never calls `attachSurfaceScript()` (`:667`). `Finalize` (`:599-602`) clears the marker and fence but doesn't publish.
   - **Consequence:** after Construct, the frame only changes on Hold, Measure and Resume. After Finalize, no newer prefixed `normal/0` frame with an unarmed fence ever appears, so the planned finalize hook can only time out. The harness's `update_agent` would raise here because `onUpdate` is nil, and the finalize test (`test_addon.py:416-433`) never looks at a frame.
   - **Correction:** attach the OnUpdate script right after a successful `createSurface` in `constructDeferred`, and call `safePublish()` at the end of `Finalize`. Test that the sequence advances after Construct, and decode a post-Finalize frame.

3. **The native gating changes the public wire, and the production decoder rejects it.**
   - **Where:** the fence projection uses reason `native_construction` (`Scanner.lua:58-59`). `Status` adds a `blocked` phase with reasons `native_construction` / `native_construction_unknown` (`Scanner.lua:1159-1161`), which reach `pending.reason` through `Agent.lua:342-343`.
   - **Why it fails:** `protocol.py:440-441` requires an empty reason on an armed fence. `protocol.py:505-506` accepts only `queue_full` and `plan_invalid` as blocked reasons.
   - **Consequence:** every frame from `defer` until Finalize or restore-clear fails to decode, including the Construct frame that `hold_required` depends on. This also violates R3's "public status stays within ready|scheduled" and "without adding a wire field".
   - **Correction:** project the native fence as `{state="armed", reason="", command=…}`. Remove the native branch from `Status` and keep native refusal reasons only in the schedule trace. Run `decode_frame` on Agent frame bytes for every lifecycle state, as the client-contracts skill requires.

4. **A malformed marker that isn't a table crashes the load path.**
   - **Where:** with `nativeConstruction = 5` or `true`, Core correctly maps it to restore-only. Agent's `ADDON_LOADED` handler then evaluates `current.token` on a number or boolean (`Agent.lua:694-695`) and raises. Core's event dispatch has no pcall, so Commands' `ADDON_LOADED` handler never runs and no panel or Restore exists. `Commands.lua:44-46` and `Agent.lua:516,538-539` read the marker the same unguarded way.
   - **Consequence:** genuine malformed-marker recovery is impossible for wrong-type markers, which R3 explicitly maps to restore-only.
   - **Correction:** read marker state only through the validated `ns.NativeDecision()` copy, or guard with `type(...) == "table"`. Add non-table markers to the matrix tests.

## Should

   - **Fix:** clear on the first successful `safePublish` while in `restore_pending`, and add the missing test for the restore_pending load.

   - **Problem:** a recovered load (decision `restore_pending`, lifecycle `ordinary`) refuses `defer`. Meanwhile an ordinary load whose surface failed to build is still admitted.
   - **Fix:** require lifecycle `ordinary` with a constructed surface, no marker, and both fences clear.

3. **An ordinary-load constructor failure is silently swallowed** (`Agent.lua:688-689`).
