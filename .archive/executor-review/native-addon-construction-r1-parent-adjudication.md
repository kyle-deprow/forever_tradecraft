# Parent adjudication for addon closure

Accept all R1 Sol Musts and actual Opus Musts. R2 closed three parent-reproduced
issues but also left the post-Finalize recovery and stale timer cases; R3 must
close the combined source findings, not merely preserve passing fixture tests.

Accepted Opus Shoulds: normal publication callback/Finalize proof, strict wire
compatibility, recovered ordinary-load defer, visible ordinary constructor error,
legacy held/0 Resume with completion bit only at held/100, genuine logout fence
projection, hidden/disabled click behavior, and the closed marker/lifecycle matrix.

Two implementation adjudications avoid an unnecessary redesign:
- Use Sol's transactional cleanup after a failed first Construct/restore
  publication. Do not add Opus's optional later-periodic-publication retry;
  failure stays explicit and Restore remains the recovery path.
- The actor and nonce stay addon-owned, reached through the fixed Commands slash
  entry without a test-only/manual admission call. A private generator in Agent
  instead of Commands is accepted as a module placement choice; panel ownership
  remains Commands. Moving the generator alone adds no execution guarantee.

Do not add a numeric timestamp parser for the boot generator. The approved marker
contract is a bounded opaque boot and the production protocol validates an opaque
string up to96 bytes. Keep the64-byte token bound and control/whitespace checks;
exact expected B0 binding is the daemon's responsibility. This rejects the
nonblocking request to infer a narrower contract from one randomBoot generator.

All live client pixels, button callback delivery, ReloadUI and installed source
checks remain future qualification evidence. Source tests make no live claim.
