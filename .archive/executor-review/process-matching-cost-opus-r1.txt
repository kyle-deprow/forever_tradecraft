## Nits
1. **`tests/test_session_driver_actions.py:523`: the test name overclaims.** `test_process_executable_exec_transition_never_accepts_mixed_generation` claims more than the code guarantees.
   - Counterexample: a matching process execs to a non-matching argv but keeps comm `CrowleyTest.exe` with the same loader and prefix. Its start time doesn't change across `exec`, so both the old and new code accept it with the old `cmdline`.
   - **Effect:** the name implies an atomicity guarantee that the implementation plan explicitly says not to promise.
   - **Fix:** rename it to something like `…_exec_transition_decides_on_read_cmdline_and_rescans_fresh`, or add a one-line comment saying the guarantee is "decide on this call's cmdline, then rescan fresh", not atomicity.
