## Must-fix

1. **The native fence makes every armed/constructed Agent frame fail the existing strict wire validator.** `addon/Crowley/Scanner.lua:56-61` projects the native cause as `scheduleFence={state="armed", reason="native_construction", ...}`, while the unchanged protocol requires an empty reason for every non-refused fence. `addon/Crowley/Scanner.lua:1159-1161` also changes the public scanner phase to `blocked` with `native_construction`; `addon/Crowley/Agent.lua:342-343` copies that into `pending.blocked/reason`, whose unchanged validator permits only `queue_full` or `plan_invalid`. This affects the still-ordinary frame immediately after `agent defer` and every prefixed frame after Construct, so the pre-reload recovery case and `hold_required` proof cannot decode. Keep construction blocking private, preserve the existing `ready|scheduled` public status, and project an armed native fence with the existing empty-reason schema. Add real `decode_frame` assertions for a post-defer `B0` frame and the first post-Construct prefixed `normal/0` frame, including the armed fence.

2. **The fixed recovery command is unreachable through the real slash/button path and does not switch the panel to restore-only mode.** `addon/Crowley/Commands.lua:182-183` accepts `/crowley agent recover` only after `Agent.RecoveryAdmitted()` is already true, but the only setter is the public Lua-only `Agent.AdmitRecovery()` at `addon/Crowley/Agent.lua:524-527`; no production event, slash command, or button calls it. The test bypasses the operator path by calling that method directly at `tests/test_addon.py:395`. Even after that bypass, the successful command does not call `updatePanel`, so the already-visible Construct control remains visible despite `BeginRecovery()` setting recovery mode. The exact no-argument slash command must perform the addon-local admission and refresh the panel in one reachable transition, while extra arguments and every Restore click before that transition remain inert. Test only the actual slash and button callbacks: pre-command Restore must preserve all state, the exact command must hide Construct and retain Restore, and the first Restore click must write the addon-owned nonce and request one reload without any direct Agent admission call.

3. **Restore does not implement the required native control and timer state machine.** `addon/Crowley/Commands.lua:40-50,72-80` only shows/hides the buttons and never disables either one, although the harness added `SetEnabled` support. After a successful Restore, the visible button therefore remains clickable instead of both controls being disabled. The two-second callback at `addon/Crowley/Agent.lua:579-585` compares only state and load ID, not the generated recovery token, and merely flips an Agent boolean; it neither re-enables nor refreshes the Commands-owned control. A different `restore_pending` marker in the same load can therefore satisfy the stale timer. On the successful recovery load, `addon/Crowley/Agent.lua:710-714` clears the marker and enters ordinary lifecycle, but `addon/Crowley/Commands.lua:42-49` still shows the panel because the intentionally immutable boot decision remains `restore_pending`. Commands needs an explicit disabled/in-flight projection owned with the panel, the timer must bind the exact nonce and load and notify Commands on a matching fallback, and a successfully restored ordinary lifecycle must hide the panel. Cover enabled/visible state, changed-token timer refusal, same-token fallback, and the next ordinary-load cleanup through real callbacks.

4. **Construct and restore-load success are committed before a successful initial publication.** The deferred constructor writes `constructed`, returns success, and lets Commands print acceptance before calling the error-swallowing `safePublish` at `addon/Crowley/Agent.lua:556-561`. A serialization, native telemetry, compression, or raster failure therefore leaves a durable constructed marker and surface without the strict prefixed frame required for `hold_required`, rather than recording `failed` and cleaning the surface. The restore-pending branch similarly attaches `OnUpdate` before its first publication at `addon/Crowley/Agent.lua:706-715`; if that publication fails, it leaves a live surface in `restore_pending`, and a later successful periodic publication has no path that clears the marker or native fence. Make construction success contingent on the first successful strict `normal/0` publication. On failure, detach scripts, hide all partial frames/textures, preserve the fence and Restore path, and store the specified failed/restore-only state. Add injected publication-failure cases for both deferred Construct and `restore_pending` load, followed by assertions that no Agent frame or active surface remains and that recovery is still available.

5. **The controls have no native visual definition even though the helper must find them as pixels.** `addon/Crowley/Commands.lua:54-75` creates a bare Frame and two bare Buttons, then only calls `SetText`; it supplies no button template, FontString/font object, normal/pushed/highlight texture, or panel art. The harness's `SetText` implementation at `tests/wow_harness.py:197-201` stores a Python-visible property and therefore treats these controls as visible/clickable without establishing any renderable native pixels. Give both controls a pinned native template or explicit reviewed font/texture construction and have the harness retain/assert that native visual contract. Later live qualification can measure the final pixels, but the source slice must first construct something the native client can visibly render and OCR.
